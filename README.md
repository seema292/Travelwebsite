# Wild Path Safari

Official Wildlife Safari Booking & Packages website. Explore India's premier tiger reserves with authentic 4x4 Gypsy & Canter safaris. Book Jim Corbett, Tadoba, Ranthambore, Kaziranga, and Gir with transparent pricing.

## Features
- **Destinations Showcase**: Detailed national park guides, zones, and safari timings.
- **Safari Packages**: Tailored wildlife tour packages across India.
- **Online Booking Flow**: Safari slot and tour reservation workflows.
- **Interactive UI**: Responsive layouts, clean typography, and Lucide icons.

## Pages
- `index.html` - Homepage
- `destinations.html` - Wildlife destinations & parks
- `packages.html` - Tour & safari packages
- `safari-booking.html` - Safari reservation page
- `contact.html` - Contact & inquiry
- `paynow.html` - Payment processing page

## Quick Start
You can preview the website locally using Python's built-in HTTP server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your web browser.
